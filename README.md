# Desarrollo Web — Mi aprendizaje

## 📖 Sobre el proyecto

Este repositorio contiene mis apuntes, ejercicios y prácticas del libro **HTML & CSS: Design and Build Websites**, de Jon Duckett.

El objetivo es aprender desarrollo web desde cero, comprender cada concepto y llevar un registro de mi progreso.

## 🎯 Objetivos

- Aprender la estructura de HTML.
- Comprender cómo funcionan las páginas web.
- Aprender a diseñar sitios web utilizando CSS.
- Practicar los ejemplos de cada capítulo.
- Documentar lo aprendido.
- Aprender a utilizar Git y GitHub.

## 📂 Organización

Cada capítulo tendrá su propia carpeta, donde guardaré:

- Ejemplos de código.
- Ejercicios prácticos.
- Apuntes y explicaciones.
- Lo que aprendí en el capítulo.
